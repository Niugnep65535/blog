---
title: 我放棄自架 Gitea 了
date: 2026-11-17
---
自架之後遇上了一連串鳥事。

Gitea Runner 斷掉、網頁出問題（1013）、更新壓力...全都會出現在你開始自架之後。

我決定回來用 GitHub。

## 打包
其實效率挺高的。我是修改原本留言板倉庫名稱，其他內容直接從我的 Gitea 整個複製過來。前後花上三分鐘，不快也不慢。

然後就是修改 runner 配置跟 DNS，把 CNAME 換成 GitHub Pages。

這裡我選擇的是「僅 DNS」，也就是不開啟 Cloudflare Proxy。

其實這屬於私人恩怨。某次我上傳一堆檔案到 Gitea，然後 Cloudflare 直接掐斷連線！因為免費板只有 100 MB 的單次請求上傳量，導致使用 tunnel 之後自架的比付費服務還難用。

所以本站的 HTTPS 是讓 GitHub 自動續杯的 Let's Encrypt。聽不懂沒關係，反正不會像剛剛（11/17 8:30 前後）一樣突然顯示不安全了。

出問題的狀況就...基本沒有。除了要檢查 DNS 加上超白Ｏ的證書快取導致誤判（這玩意快取幹嘛）
