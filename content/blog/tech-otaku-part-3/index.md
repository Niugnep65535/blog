書接[上回](/blog/tech-otaku-part-2/)，我提到我改用了 crDroid。

然後我又變成了 half-degoogle。

目前的狀態是刷了個 GrapheneOS，然後加上 GMS 服務，給一點點權限。

老實講我有些後悔，一來我用不上 GrapheneOS 的安全性功能，那是給戰地記者跟國家級間諜用的；二來 crDroid 自由度明顯更高，也有超好用的各種功能。

## 走火入魔與回歸務實
我曾經對自由軟體有高度要求，現在已經放棄如此高度的要求。

我累了。

放棄成為完全的真．技術宅，讓我省下了修理、自我矛盾、自我糾察的時間。

比如 Wiwi 提到真．技術宅應該使用自架為主，但是台電一個月斷我伺服器兩次電，加上中華電信那個大便網路就讓我很上火（我上個月都斷八次了），最後還是回到本機與 GitHub 等方案。

說難聽點我放棄了自己的自由換來便利，但是我是個中學生。

我沒錢沒時間，在晚自習[修理 Gitea Runner](/blog/gave-up-gitea) 是我的極限，更不用說在荒島上的無聊。

**我累了！**

## 對照表與做法
這裡是照搬 Wiwi 的[《假宅男 vs 真宅男》](https://wiwi.blog/blog/fake-vs-real-tech-nerd/)並修改。

| 方面 | 假宅男 | 真．宅男 | 我的作法 |
| --- | --- | --- | --- |
| 🌟 **核心價值** | 方便、簡單、漂亮、主流的最好 | 注重隱私、自由、所有權、自力更生、對主流說法持懷疑態度 | 追求隱私、自由、所有權等，但是也追求便利；對主流說法持懷疑態度 |
| 🖥️ **科技態度** | 消費主義、被動接受預設值 | DIY 精神、客製化、理解自己使用的工具的運作方式 | 理解運作方式後回到預設值 |
| 🌐 **世界觀** | 科技是別人提供的服務 | 科技是需要自己掌握的工具 | 科技只是中立的技術 |
| 📊 **個資** | 用個資交換免費服務 | 強調個資所有權和控制權 | 一點點個資換免費服務，剩下的自己來 |
| 🕵️ **隱私** | 我又沒做壞事，有什麼好隱藏的 | 覺得隱私是基本權利，理解資料外洩可能的後果 | 隱私是基本權利，只能交一點點 |
| 🆓 **軟體** | 接受專有軟體 | 強烈偏好自由、開放原始碼軟體 | 偏好自由、開源軟體（沒有強烈） |
| 🔧 **硬體** | 最新產品出來就要買 | 讓老舊筆電起死回生才有成就感 | 讓老舊筆電起死回生才有成就感 |
| 📺 **內容消費** | 主流媒體、演算法推給我什麼就看什麼 | 尋求精心製作的高品質內容 | RSS 訂閱高品質內容 |
| 👥 **社交互動** | 大型社群媒體、公開分享自己的一舉一動 | 自有網站、選擇性地分享個人資訊 | 自有網站為主，部分社群為輔，選擇性地分享個人資訊 |
| 📡 **資訊接收** | 一直不斷地查看最新資訊 | 有意識地定期查看資訊 | 不定期隨便看看 |
| 🔍 **問題解決** | 尋求客戶支援、壞了就換 | 自行排除故障、修復和改進 | 自行排除故障、修復和改進 | 
| 💾 **資料儲存** | 依賴大科技公司的雲端方案 | 自有 NAS、多地備份 | 存直連硬碟最安全 |
| 🤖 **對 AI 的態度** | ChatGPT 好方便、用到爆 | 線上 AI 是很強大沒錯，但也自行準備離線的語言模型方案，避免依賴線上服務 | 線上 AI 很強大且依賴，因為 3050M 是丐幫玩意 |
| 🚫 **對廣告的態度** | 只好接受，不然怎麼辦 | 強烈反感、使用 ad-blockers | 強烈反感、使用 ad-blockers |
| 📡 **對監控的態度** | 不知道、不 care | 高度關注、積極避免 | 高度關注、積極避免 |
| 🏢 **對大科技公司的態度** | 信任和依賴 | 懷疑和避免 | 依賴但監督 |
| 💰 **對訂閱的態度** | 覺得訂閱服務是常態 | 盡可能避免訂閱制，偏好一次性購買、自架解決方案 | 盡可能使用免費替代方案 |
| 💪 **數位韌性** | 依賴各種網路服務完成日常工作 | 為服務中斷做好準備 | 為服務中斷盡量做好準備 |
| 📐 **檔案格式** | 接受專有格式、忍受 DRM | 強烈偏好開放標準、拒絕 DRM | 偏好開放標準、拒絕 DRM |

把兩邊的想法塞果汁機裡打爛。

順帶一提，Wiwi 的 [footnotes](https://wiwi.blog/blog/fake-vs-real-tech-nerd/#user-content-fn-1-0ae310) 還有個「真．超宅男」。按照他前面的寫法，這想都不用想就知道是 RMS 那一掛的。那種誰愛用誰用，我不愛用。
