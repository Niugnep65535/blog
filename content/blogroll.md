這裡是我的部落捲，收錄了一些我喜歡、覺得有趣，或值得認識的部落格。

部落捲（blogroll）是一種部落格文化中的傳統，列出站長推薦的其他網站，讓讀者能透過彼此的連結探索更多有趣的角落。比起演算法推薦，這裡更像是網路上的口耳相傳。

排名不代表推薦程度，個人評語也純屬個人觀感。

- "夜星見 — The Never Ending Dreaming" (https://yoruhosimi.pixnet.net/blog/)
  
  - 介紹： 夜星見的創作用部落格＊
  - 評語： 我媽的吃灰部落格，媽媽一定得放第一個對吧。

- "Ivon 的部落格" (https://ivonblog.com/)
  
  - 介紹： 分享 GNU/Linux 情報、自由開源軟體、電腦手機資訊、人文思辨的所在＊
  - 評語： 上學千萬別看，要是他剛發 NSFW 就完了。

- "豆子 Bean" (https://mamegoodbean.pixnet.net/blog/)
  
  - 介紹： 豆子在痞客邦的小天地＊
  - 評語： 我的舊部落格，歡迎盜墓。

- "编程随想的博客" (https://program-think.blogspot.com/?m=1)
  
  - 介紹： 中國大陸 IT 行業從業者、部落客作家、異見人士。
  - 評語： 誰說淤泥滿身的不算英雄？

- "Wiwi 官大為的部落格" (https://wiwi.blog/)
  
  - 介紹： Wiwi 官大為發廢文和分享經驗的地方。
  - 評語： 很少看到用 GrapheneOS 的人了。

- "Richard Stallman's Personal Site" (https://www.stallman.org/)
  
  - 介紹： Richard Stallman 的個人網站。
  - 評語： bro 已經走火入魔了。

- "A吉胖的部落格" (https://fatapple0406.github.io/)
  
  - 介紹： 放置各種隨興創作、日常紀錄和人生啟發的地方＊
  - 評語： 怎麼到哪都有腐。

- "Leaftechblog" (https://www.leaftechblog.cloudns.biz/)
  
  - 介紹： Leaf 的科技部落格。
  - 評語： 挖過 CVE 的大佬。

- "SamHacker Blog" (https://blog.samhacker.xyz/)
  
  - 介紹： 一個熱愛 Coding 的高中生的科技部落格。
  - 評語： 這麼可愛一定是男孩子對吧。

- "It's 小白不是小白" (https://itsxiaobai.codeberg.page/pages)
  
  - 介紹： 喜歡開源跟自由軟體，偶爾玩一下混音的高中生。
  - 評語： 哥們部落格太像 Wiwi 的了吧。

- "心是灵的博客" (https://blog.xinsl.xin/)
  
  - 介紹： 發表一些電腦使用技巧與個人觀點的地方。
  - 評語： 哥們小心點 pwp。

- "Tommy's blog" (https://calke.bearblog.dev/)
  
  - 介紹： 一個國中生（國一）創的簡單部落格。＊
  - 評語： 現在居然也有國一生開部落格，抽到 SSR 了。

＊表示介紹來自該網站的官方說明。
