比賽前#

早餐是麥當勞。
我選的是豬肉滿福堡+咖啡，其實挺好吃的，但是我咖啡在捷運上撒了，還好沒什麼事。

比賽項目1#

比賽項目1就是實作程式，這次的題目是微信滬想生活。
說白了就是個聊天軟體，參加了青年組商軟設計應該會有印象。
這次給的資料庫與以往不一樣，給的是.sql檔案，也就是SQL查詢語言的腳本檔案，要用這檔案建立資料庫。令我不解的是，一堆人不知道這幹嘛的。
然後就是Entity Framework了。它是一個讓SQL查詢沒那麼反人類的.NET工具。比如SQL指令長這樣：

SELECT *
FROM users
WHERE type = 'homo';

然後Entity Framework長這樣：

using (var db = new Entities()){
	var homos = db.users.Where(x => x.type == homo);
}

看起來舒服了吧！
但是我的EF卻一直炸一直炸，後來才發現居然是引用了System.Data，要引用System.Data.Entity.Core才能繼續用…
我是很不清楚我的分數如何，因為好像只有我把這堆SQL修好，但程式部份我又沒做完…

比賽項目2、3#

然後就是簡報了。
簡報部份要用到PowerPoint跟Visio，整個比賽就是微軟全家桶。
這個簡報其實我沒有太多素材，因為沒做完。雖然可從範例截圖，但我當時沒想到。

報告的部份每個人各有風格，其中有幾位我比較有印象的：

  • 一個用英文講的同學
  • 一個只有簡報不報告的同學
  • 好幾個全中文的同學（簡報要求英文；報告語言不拘）
  • 還有個直接攤牌「我沒做簡報」的

最後一個就看我旁邊那位在憋笑。

明天再見！#
