或許，Debian？

不得不說，我真的是個很容易受別人左右的傢伙。 今天一打開信箱，就看到有一位來自對岸的讀者「心是靈」（他的部落格）在我的crDroid使用心得下留言，還附帶了自己的部落格連結，我想都沒想就點進去看。 他寫了篇名為《I Use Debian, btw.》的文章，提到了為什麼他沒有繼續使用Arch，而是改用Debian。 他說的沒錯 他提到的三個問題：滾動更新、軟體生態跟社區狀態我都懂。 我也不是沒滾掛過 也不是沒遇過軟體只給.deb 更不是沒遇過制仗老手給新手推原生Arch配tiling WM的 而且他還提到NVIDIA有官方Debian 13驅動倉庫！這又讓我更想再試一次Debian了。 我的狀況 嘛，我現在跑去用Debian一定會下意識輸入sudo pacman -Syu然後報錯。 不過我會以雙系統或者雙機的方式，同時使用Debian跟Arch。 自肥 You see，我用的是Arch，寫這文章也是用Arch，然後加上KDE Plasma桌面環境，跟心是靈用的Debian + GNOME完全是兩個極端，然後我寫文章沒跟他吵。所以我可以以此證明我有風範。（臭不要臉 新手別學！ 自從我媽幫我推部落格之後，我就很清楚會有很多圈外朋友會看到我寫這種文章。如果你沒有用過Linux，麻煩考慮一下Linux Mint，那個才是給新手用的。（包含我也是Mint入坑）

你需要Linux，不要拖了

這篇文章在7/30就寫好了，但是因為我怕今天也寫了一篇會太過頻繁，所以就設定7/31發布。 是的！你需要Linux！ 這樣我說話的口吻像是Wiwi官大為似的（舉例），但是這真的很重要。 Linux是什麼？ 一個由Linus Torvalds撰寫的系統核心，最大特點就是開源。因為這一點，你可以在各種電腦上安裝。小至幾十台幣的控制器，大至世界前五百大超級電腦，都是用Linux。 你可能覺得這跟你無關，但是實際上，Windows正在變得越來越爛，比如自動更新、監視等。 舉個例子。假如我今天製作一個茶壺，很多人用，但是後來的產品加上了廣告和監視器，怎麼辦？ 好說嘛，換一個牌子唄。 為什麼同樣的道理你不換掉Windows呢？作業系統跟茶壺一樣都是工具，為什麼你可以忍受作業系統變爛，不能忍受茶壺變爛呢？你一天泡茶的時間應該比用電腦的時間少吧？ 而且macOS也有同樣的問題，不要以為用Mac就沒差。 Linux好多！ Linux只是個核心，但是作業系統本體有很多，它們叫做發行版，各自代表不同的理念。 光是我舉得出的例子就有： Linux Mint Debian Linux Arch Linux Fedora Linux Pop!_OS Red Hat Enterprise Linux（企業用的） Ubuntu SteamOS 以及千百種發行版 那麼你該選哪個系統呢？ 對於新手而言，最穩定的肯定是Linux Mint。 它不花錢、有大量教學跟論壇、簡單易用，而且長的像Windows，轉移難度低。 如果你是馬上上戰場的新手大學生，我強烈建議在虛擬機裝個Fedora。 企業很多都是用RHEL，它的組件管理工具（dnf install <東西>）跟Fedora相通，可以盡早練習。 延伸閱讀 Wiwi - 你的電腦不是你的 Ivon - 【2026年】適合新手入門的GNU/Linux發行版

我媽的Linux Mint使用記

昨天我讓我媽試用了一下Linux Mint，我現在不認為它是對新手最好的發行版了 （拿親媽當白老鼠，真是個「大孝子」） Mint最大的問題：輸入法 在中文環境下，它預設沒有輸入法；官方給的輸入法教學也是殘廢的，甚至還是上世紀Fcitx 4跟IBus引擎。 真的要使用輸入法，還得去程式商店找Fcitx 5跟新酷音。 我想問哪個新手會知道這些？ 當然，你可以自己去查Wiki。但是現在我身邊這群麻瓜可能連維基百科是什麼都沒用過，怎麼指望他們查Wiki？ 之後的嘗試 因為我突然想到，Kubuntu預設有提供輸入法，今晚試試。
