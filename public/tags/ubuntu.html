Distro Hopping的一點皮毛筆記

因為這陣子常常換系統（Arch -> Debian -> Ubuntu -> Kubuntu），決定把換系統的操作整理一下給大家參考。 準備工作 備份家目錄下的.ssh資料夾 mkdir <隨身碟>/ssh cp -r ~/.ssh/* <隨身碟>/ssh 匯出GPG金鑰： gpg --export <金鑰ID> > gpg_public.asc # 匯出公鑰 gpg --export-secret-keys <金鑰ID> > gpg_private.asc # 匯出私鑰 備份沒有上傳到雲端/GitHub的專案、音樂、圖片等 備份設定文件（位在.config下，對kitty、Hyprland等使用設定檔設定的軟體尤其重要） 備份瀏覽器設定（可選） 正式安裝 主要分為以下步驟： 更新系統 升級系統（如果是舊版point release） 安裝驅動 解除安裝Snap（Ubuntu系，可選） 安裝Flatpak（可選） 安裝必要軟體 還原設定、還原資料 更新系統 依照發行版派系有所不同： # Debian / Ubuntu sudo apt update; sudo apt upgrade # Arch / Manjaro / CachyOS sudo pacman -Syu # Fedora / RHEL / Rocky sudo dnf upgrade --refresh 對於Linux Mint，可以透過更新管理員進行更新；對於KDE neon，建議透過Discover應用程式更新。 ...
